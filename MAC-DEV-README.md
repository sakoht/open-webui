Mac Dev README
==============

Run this to install things on the Mac for development:
```
./mac-build.sh
```

Run this to start the service in docker-compose with local directories mounted into the container:
```
./mac-start-docker.sh
```

Run this to run directly on your Mac, no docker:
```
./mac-start-local.sh
```

There are also run configurations for PyCharm in the `.run` directory.  You may need to edit parts that contain full paths from my laptop.
